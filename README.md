# Amile's Drive [Rustenburg]

A small space game: fly a red roadster past the Moon toward Mars, dodging asteroids, satellites and comets.
Hold to fire the underbody thrusters, rotate with the arrow keys (or the round buttons on a touchscreen), and flip it right round for points.

It is one HTML page with no downloads, and it keeps a copy on the device so it opens without internet.
On an iPhone or iPad: open the site in Safari, tap Share, then Add to Home Screen.
